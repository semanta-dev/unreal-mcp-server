Defects these tests found and fixed on the way (each with a unit test that fails without the fix):
- `pie op=aim` gave up after a large one-tick mouse delta overshot (a 90° request turned 193°): it learned a wrong
  gain and called the axis stuck. Steps are now capped at 45°, off readings shrink the step instead of being learned,
  and an axis is stuck only after two non-turning steps.
- `level op=open` / `op=revert` reported success when the editor fell back to an untitled map (the file was gone):
  the open world is now checked.
- The suite's own first cleanup force-deleted an in-use widget (`delete_loaded_asset`): an engine ensure followed and
  `L_Arena.umap` disappeared from disk. Tests now only plain-delete, which refuses assets in use.
